# Osman Can Kandemiroglu — Academic Website

Source for my personal academic website: a single, self-contained `index.html` page
presenting my research profile, methods and technical skills, research experience,
education, and publications.

**Research areas:** organic geochemistry · microbial biogeochemistry ·
stable-isotope geochemistry · lipid biomarkers.

## Viewing locally

Open `index.html` in any browser — there is no build step and no dependencies.

## Hosting on GitHub Pages

1. Repository → **Settings** → **Pages**
2. **Source:** *Deploy from a branch*, select your branch and `/ (root)`
3. Save — the site will be available at `https://cankandemiroglu.github.io/ock/`.

## Structure

- `index.html` — the complete site (HTML + CSS + a small theme toggle), light/dark aware.
