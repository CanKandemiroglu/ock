# 📄 Publish Faster — 50 Prompts for Every Stage of Getting a Paper Out

**Turn ChatGPT / Claude / Gemini into your writing accelerator — from first lit search to final proof.**
Replace anything in `[BRACKETS]`. Every prompt has role + context + constraints + output format — that's why they beat generic one-liners.

> ⚠️ **Read first — research integrity.** AI **hallucinates facts and citations**. These prompts are built to make YOU supply the science and sources, and many include a "flag anything unverified" instruction. Rules you must keep: (1) never let AI invent data or references, (2) verify every claim and citation against the real source, (3) disclose AI use where your journal/institution requires it, (4) you are the author — AI drafts, you decide. Used this way, AI is a legitimate writing aid, not misconduct.

**How to get the best results:**
1. Fill brackets with real specifics (your field, numbers, target journal).
2. Paste your own material — the more you give, the less it invents.
3. When output misses, reply: *"Good, but make it more [precise/concise/formal] and fix [X]."* Iteration is the skill.

# PART 1 — LITERATURE & READING (1–8)

## 1. The Theme Synthesizer
```
You are a meticulous research assistant in [FIELD]. I'll paste key findings from
several papers. Use ONLY what I provide — do not invent citations. Group into 3–5
themes, name each, and per theme give the consensus, the disagreements, and the
open gap. Write as a narrative with [AuthorYear] placeholders. End with a
3-sentence gap statement motivating a new study. Flag any uncertainty.
[PASTE FINDINGS]
```

## 2. The Fast Paper Digest
```
Digest this paper for me. Output: (1) the question in one sentence, (2) methods in
3 bullets, (3) the 3 key results with numbers, (4) the main limitation, (5) how it
relates to my work on [MY TOPIC], (6) one question I could ask the authors. Be
accurate; quote the paper where precise wording matters.
[PASTE ABSTRACT / SECTIONS]
```

## 3. The Comparison Table Builder
```
I'll paste findings from [N] papers on [TOPIC]. Build a comparison table:
columns = study, system/sample, method, key result, limitation. Then write 3
sentences on the pattern across studies and where they conflict. Use only my
inputs; mark any cell I didn't give as "not reported".
[PASTE]
```

## 4. The Gap Finder
```
Based on these summaries of the literature on [TOPIC], identify the 5 most
defensible research gaps. For each: state the gap, the evidence it's open (from my
inputs), and a one-line study idea that would fill it. Rank by (importance ×
feasibility for a [PhD student / small lab]).
[PASTE LIT SUMMARIES]
```

## 5. The Search-Term Strategist
```
I'm doing a literature search on [TOPIC]. Generate: (a) a Boolean search string
with synonyms and field tags for Scopus/Web of Science, (b) 8 alternative keyword
clusters I might be missing, (c) 5 seminal-author or method names worth searching
directly. Note: I will run the searches — do not fabricate results.
```

## 6. The Concept Explainer (3 levels)
```
Explain "[CONCEPT]" at three levels: smart 12-year-old (analogy, 4 sentences),
undergrad in [FIELD] (mechanism, ~120 words), specialist (equations/parameters/
edge cases). Then: 3 common misconceptions and 2 talk-ready analogies. Flag
anything contested.
```

## 7. The Annotated-Bibliography Drafter
```
For each source I paste (citation + my notes), write a 4-sentence annotation:
what they did, key finding, strength/weakness, relevance to my project on [TOPIC].
Consistent academic tone. Do not add sources or claims beyond my notes.
[PASTE SOURCES + NOTES]
```

## 8. The Devil's-Advocate Reader
```
You are a skeptical reviewer. Here is a paper/claim central to my argument:
[PASTE]. List the strongest 5 critiques of its methods, statistics, or
interpretation, and for each, how I should account for it in my own work. Be fair,
not contrarian for its own sake.
```

# PART 2 — DRAFTING THE PAPER (9–20)

## 9. The Outline Architect
```
You are a co-author in [FIELD]. Build a section-by-section outline for a paper
titled "[WORKING TITLE]" for [TARGET JOURNAL]. My main finding: [FINDING]. For
each section list the 2–4 points it must make and the one figure/table it anchors
on. Match the journal's typical structure and length.
```

## 10. The Introduction Funnel
```
Draft an Introduction for my paper following the funnel: broad importance → what's
known → the specific gap → our approach → what this paper does (aims/hypothesis).
4 paragraphs, [AuthorYear] placeholders (no invented refs), ends with a crisp aim
sentence. No "in today's world" clichés.
Field: [FIELD]. Gap: [GAP]. Our contribution: [CONTRIBUTION].
```

## 11. The Methods Cleaner
```
Turn my notes into a reproducible Methods section. Past tense, replicable detail
(instruments make/model, settings, quantities, controls, replicates, software +
version), logical subsections, and a final data-analysis paragraph. Insert
[PLACEHOLDER] where I omitted detail and list the gaps. Invent nothing.
[PASTE NOTES]
```

## 12. The Results Narrator
```
Write the Results section from my data. Rules: report, don't interpret (save that
for Discussion); reference figures/tables as [Fig. X]; state actual numbers,
effect sizes and stats I provide; logical order (often matching the aims). Flag
any result that seems to need a statistical test I didn't mention.
My results: [PASTE with numbers]
```

## 13. The Discussion Builder
```
Help me write the Discussion. Structure: restate main finding & whether it
answered the question → interpret each key result mechanistically → compare to
prior work ([AuthorYear] placeholders, only comparisons I confirm) → 2–3 honest
limitations → 2–3 future directions → strong significance close. Hedge
appropriately; no overclaiming.
Key results: [PASTE]
```

## 14. The Abstract (structured)
```
Write a ≤250-word structured abstract: background (2 sentences), objective (1),
methods (2), results with my numbers (2–3), conclusion & significance (2). Active
voice, no hype, no undefined acronyms. Add 5 keywords and a one-line plain-language
significance statement.
Study: question [Q], methods [M], results [R], conclusion [C].
```

## 15. The Cover-Letter Writer
```
Write a submission cover letter to the Editor of [JOURNAL] for my manuscript
"[TITLE]". One page: the question and why it fits the journal's scope and readers,
the key advance in 2 sentences, confirmation of originality/ethics, and suggested
(or excluded) reviewers placeholder. Confident, concise, not boastful.
Key advance: [X]. Why this journal: [Y].
```

## 16. The Highlights / Graphical-Abstract Scripter
```
From my paper's key points, write: (a) 5 "highlights" bullet points (≤85 chars
each, one finding each, active voice), and (b) a text description/brief for a
graphical abstract — what panels to show, the flow, and the single message a
reader should get in 5 seconds.
Key points: [PASTE]
```

## 17. The Plain-Language Summary
```
Write a plain-language summary of my study for a non-specialist (funding body /
press / public). ~150 words, no jargon (or define it), answer: what did we do, what
did we find, why does it matter to people. Accurate, not exaggerated.
Study: [PASTE ABSTRACT]
```

## 18. The Contribution Statement + Keywords
```
Based on my paper, draft: (a) a CRediT-style author-contribution statement from
the roles I list, (b) 6 keywords balancing discoverability and specificity, (c) a
one-sentence "novelty statement" I can reuse in the cover letter and abstract.
Authors & roles: [LIST]. Topic: [TOPIC].
```

## 19. The Thesis-Chapter Converter
```
I need to turn my thesis chapter into a journal article (or vice versa). Given my
[chapter/paper] outline: [PASTE], tell me what to cut, condense, or expand, how to
reframe the intro and discussion for [TARGET], and a mapping table (thesis section
→ paper section). Flag redundancy.
```

## 20. The Co-Author Merge
```
I have text from multiple co-authors with clashing styles: [PASTE SECTIONS].
Harmonize into one consistent voice (tense, terminology, [US/UK] spelling,
acronym use) without changing meaning or claims. List any factual conflicts
between sections for me to resolve — don't silently pick one.
```

# PART 3 — FIGURES, DATA & STATS (21–28)

## 21. The Figure Caption Writer
```
Write a self-contained caption for a figure showing [DESCRIBE: axes, conditions,
what's plotted]. Include what it shows, the key comparison, symbol/error-bar
definitions, n, and the statistical test. Journal style, one paragraph. Then
suggest a takeaway title for the figure.
```

## 22. The Figure Critic
```
Here's a description of my figure: [DESCRIBE]. Critique it for clarity and honesty:
is the chart type right for the data, are axes/scales fair (no truncation
tricks), is it colorblind-safe, what's redundant, what's missing (n, units, error
bars)? Give a prioritized fix list.
```

## 23. The Stats Advisor (sanity check, not a substitute)
```
You are a statistics tutor. My design: [DESCRIBE: groups, sample sizes, what I
measured, paired/unpaired, distribution if known]. Recommend appropriate
statistical test(s), the assumptions I must check, and how to report the result
(what numbers to include). Note pitfalls (multiple comparisons, pseudoreplication).
I will run and verify the analysis myself.
```

## 24. The Results-to-Prose Translator
```
Convert this statistical output into correct, journal-ready sentences: [PASTE
OUTPUT — means, SDs, test statistic, df, p, effect size, CI]. Report effect sizes
and CIs, not just p-values. Don't overstate; "significant" ≠ "large". Give me the
exact sentences to paste.
```

## 25. The Data-Cleaning Plan (for Python/R)
```
I have a dataset: [DESCRIBE columns, size, source, known issues]. Write a step-by-
step cleaning plan and the [Python pandas / R tidyverse] code skeleton to: load,
inspect, handle missing values and outliers (state the rule), fix types, and
produce a tidy table. Comment each step. I'll run and check it.
```

## 26. The Plotting Code Generator
```
Write [matplotlib / ggplot2] code to make a publication-quality [chart type] of
[WHAT], with [X] on x-axis and [Y] on y-axis, grouped by [GROUP]. Requirements:
colorblind-safe palette, labeled axes with units, readable font sizes, error bars
from [SOURCE], and export at 300 dpi. Add comments. Assume my data is in
[format/columns].
```

## 27. The Reproducibility Checklist
```
Given my study [DESCRIBE], generate a reproducibility checklist covering: data
availability, code/scripts, software versions, random seeds, raw vs processed
data, and what to deposit where (repository suggestions). Format so I can tick it
before submission.
```

## 28. The Supplementary Organizer
```
Help me decide what goes in the main text vs supplement for [JOURNAL]. Given my
list of figures/tables/analyses: [PASTE], recommend placement, suggest a logical
supplement structure with numbering (Fig. S1...), and draft the "see Supplementary
Information" pointers for the main text.
```

# PART 4 — REVISION & PEER REVIEW (29–38)

## 29. The Reviewer Rebuttal Engine
```
You are an experienced corresponding author writing a point-by-point response.
Gracious, evidence-based, never defensive. Per comment: restate it, acknowledge
(vary wording), state exactly what changed (new text in quotes + [section]
pointer), and if disagreeing, concede the valid part then give a reasoned
rebuttal. Flag comments needing new data vs text edits.
Reviewer comments: [PASTE]
```

## 30. The Tone Softener
```
My rebuttal reply below sounds defensive/annoyed: [PASTE]. Rewrite it to be
professional, warm, and confident without conceding scientific ground I shouldn't.
Keep the substance; fix only the tone. Give me the clean version.
```

## 31. The Reviewer (self-review before submission)
```
You are a tough but fair Reviewer 2 for [JOURNAL]. Review my manuscript: [PASTE
or SUMMARIZE]. Give: 3 major concerns, 5 minor comments, and the likely
recommendation (reject / major / minor / accept) with reasons. Be specific enough
that I can fix things before real reviewers see them.
```

## 32. The Weakness Pre-empter
```
What are the 5 most likely reviewer objections to my study on [TOPIC] with
[METHOD/DESIGN]? For each, tell me whether to (a) address it with new analysis,
(b) add a caveat in the discussion, or (c) prepare a rebuttal — and draft the
caveat/rebuttal text.
```

## 33. The Revision Change-Log
```
I made these changes to my manuscript: [LIST]. Write a clean "Summary of Changes"
document for the editor: grouped by theme, each change with a before/after or a
[section/line] pointer, in the order reviewers will look for them. Concise and
easy to audit.
```

## 34. The Decision-Letter Interpreter
```
Interpret this editor decision letter honestly: [PASTE]. Tell me: is this really
"revise & resubmit" or a soft reject? Which comments are dealbreakers vs optional?
What's the realistic effort and my best strategy? Draft a 3-line reply to the
editor if one is warranted.
```

## 35. The Appeal Letter (use sparingly)
```
My paper was rejected and I believe a reviewer misunderstood [ISSUE]. Help me
decide if an appeal is justified (be honest — most aren't), and if so, draft a
short, respectful appeal to the editor that focuses on the specific factual
misunderstanding with evidence, not on emotion.
```

## 36. The Consistency Sweep
```
Check my manuscript excerpt for internal consistency: [PASTE]. Flag mismatches in
numbers (abstract vs results), terminology, acronym definitions, tense, tense of
figure references, and citation style. List each issue with location — don't
rewrite unless I ask.
```

## 37. The Journal Reformatter
```
I'm moving my manuscript from [JOURNAL A] to [JOURNAL B]. List everything that
typically differs (reference style, section order, abstract type/length, figure
placement, word limits) and give me a checklist to reformat. If you're unsure of
B's exact rules, say so and tell me where to confirm.
```

## 38. The Response-Time Chaser
```
Draft a polite status-inquiry email to a journal editor: my manuscript [ID] has
been [under review / awaiting decision] for [TIME]. Courteous, brief, asks for an
update without demanding. Give a warmer and a firmer version.
```

# PART 5 — GRANTS, ABSTRACTS & DISSEMINATION (39–50)

## 39. The Specific-Aims Page
```
Draft a one-page Specific Aims. Hook (problem + gap + why now) → long-term goal,
objective, central hypothesis (one sentence each) → 2–3 aims with bold titles,
one-line rationale, and independent-ish approaches → payoff paragraph. Persuasive,
skimmable, one page. Flag where preliminary data is needed.
Field: [FIELD]. Problem/gap: [X]. Hypothesis: [H]. Approach: [A].
```

## 40. The Significance/Impact Writer
```
Write the Significance and Broader Impacts sections for a proposal on [TOPIC].
Significance: why the problem matters scientifically and what changes if we solve
it. Impacts: concrete benefits (training, methods, society, other fields). Avoid
vague grandiosity; tie every claim to something specific.
```

## 41. The Lay-Summary for Funders
```
Write a compelling lay summary of my proposal for a review panel that includes
non-experts. ~200 words: the problem in human terms, our idea, why we're the ones
to do it, the payoff. Vivid but accurate, no jargon.
Proposal gist: [PASTE]
```

## 42. The Conference-Abstract Compressor
```
Compress my study into a [WORD LIMIT]-word conference abstract for [CONFERENCE].
Keep the single clearest finding front and center, cut background hard, end with
the takeaway. Then suggest a punchy talk/poster title.
Study: [PASTE]
```

## 43. The Poster Copy Kit
```
Write the text for a research poster on [TOPIC]: a one-line title, a 2-sentence
intro, 3 methods bullets, 3 results bullets tied to [Fig 1/2/3], and a 2-sentence
conclusion + one "so what". Scannable in 60 seconds. Then give me a 90-second
elevator pitch script for standing at the poster.
```

## 44. The Talk Builder
```
Outline a [10/15/20]-minute conference talk on my paper: slide-by-slide (title +
one-line message per slide), where each figure goes, the one takeaway to repeat,
and 3 likely audience questions with strong answers. Story arc: problem → approach
→ key result → why it matters.
Paper: [PASTE ABSTRACT + KEY FIGS]
```

## 45. The Reviewer-2-for-Grants Pre-empt
```
You are a study-section reviewer. Given my aims: [PASTE], list the top 5 concerns
a panel would raise (feasibility, significance, overlap, rigor, PI qualifications)
and how to address each in the text. Be blunt — better from you than from them.
```

## 46. The Thread / Social Summary
```
Turn my new paper into a [Twitter-X thread / LinkedIn post / Bluesky post]:
hook (the surprising finding), 4–6 posts building the story with one point each,
plain language, and a final post linking the paper and thanking co-authors/funders.
Accurate, not clickbait. Include where to add the figure.
Paper: [PASTE ABSTRACT]
```

## 47. The Press-Release Draft
```
Draft a short press release for my study: headline, dateline, 2-sentence lede with
the finding, 2 quotes (one from me — mark as [PI QUOTE], one context), a "why it
matters" paragraph, and a boilerplate line. Journalistic, accurate, no hype.
Study: [PASTE]
```

## 48. The Reviewer-Recommendation Helper
```
For my manuscript on [TOPIC/METHODS], help me draft: (a) criteria for suitable
reviewers, (b) 5 example reviewer profiles (expertise, not real names — I'll
supply names), and (c) a fair justification for excluding [COMPETITOR/CONFLICT]
that I can paste into the submission form.
```

## 49. The Response-to-Funder Report
```
Help me write a progress/final report for [FUNDER] on grant [ID]. Given my planned
aims vs what happened: [PASTE], structure it as: aims recap, achievements per aim
(with evidence), deviations and why, outputs (papers/talks/data), and next steps.
Honest about what didn't work, framed constructively.
```

## 50. The Weekly Writing Sprint Planner
```
You are my writing coach. My manuscript status: [SECTIONS DONE / TODO]. Deadline:
[DEADLINE]. Time I have: [HOURS/WEEK]. Build a week-by-week writing plan with a
concrete deliverable each week (e.g. "Methods complete draft"), the order that
minimizes blocking, and a rule for what to do when I get stuck. Realistic, not
fantasy.
```

## 🎁 Bonus: The Meta-Prompt
When any output is weak, paste this:
```
Rate your last answer 1–10 against what a rigorous senior co-author would
accept. List what's missing or imprecise, then rewrite it to a 10. Flag any
claim or citation that must be verified against a real source.
```
