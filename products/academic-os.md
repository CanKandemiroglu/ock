# AREA 1 — THESIS & DISSERTATION (1–8)

## 1. The Thesis Roadmap
```
You are a thesis advisor. My thesis on [TOPIC] is due [DATE]. Chapters planned:
[LIST]. Current status per chapter: [STATUS]. Build a realistic reverse timeline
with monthly then weekly milestones, buffer time before the deadline, and the
critical path (what blocks what). Flag where I'm being unrealistic.
```

## 2. The Chapter Skeleton
```
Draft a detailed outline for my thesis chapter "[CHAPTER TITLE]" in [FIELD].
For each section: the argument it makes, the figures/tables it needs, and its
2–4 key points. Keep it consistent with a chapter whose role is [intro / methods /
results / synthesis]. Note what I still need to produce.
```

## 3. The Literature-Chapter Synthesizer
```
Help me structure my literature review chapter on [TOPIC]. From my source notes:
[PASTE], propose a thematic (not chronological unless better) structure, name each
theme, order them to build toward my research gap, and write the linking sentences
between themes. [AuthorYear] placeholders only — no invented refs.
```

## 4. The Thesis-to-Papers Planner
```
My thesis has these chapters/results: [LIST]. Advise how to split it into
publishable papers: which results group into which paper, target journal type for
each, suggested order of submission, and what extra analysis each needs. Give a
table: paper → contents → target → gap to fill.
```

## 5. The Consistency & Formatting Auditor
```
Check this thesis excerpt for consistency: [PASTE]. Flag issues in terminology,
acronyms (defined once, used consistently), tense, number formatting, figure/table
numbering and references, and citation style. List with locations. Don't rewrite
unless asked.
```

## 6. The Abstract & Summary Set
```
From my thesis contents [PASTE], write: (a) a 300-word thesis abstract, (b) a
1-page lay summary for family/funders, (c) a 3-sentence version for my CV/website.
Consistent message across all three, no hype, accurate to what I actually found.
```

## 7. The Acknowledgements Drafter
```
Draft a warm, professional acknowledgements section for my thesis. People/groups
to thank: [LIST with role]. Order by convention (supervisors, funders,
collaborators, technical staff, peers, family). Sincere, specific, not gushing.
Give me a version I can lightly edit.
```

## 8. The "Am I Done?" Gap Check
```
You are my examiner. Given my thesis outline and status [PASTE], list what a
committee would expect that might be missing or thin: unaddressed limitations,
weak links between chapters, claims lacking evidence, or an underdeveloped
synthesis. Prioritize what to fix before submission.
```

# AREA 2 — DEFENSE & PRESENTATIONS (9–15)

## 9. The Defense Question Bank
```
You are my thesis committee. Based on my abstract and key claims [PASTE], generate
25 likely defense questions across: motivation, methods choices, statistics,
interpretation, limitations, alternative explanations, and "big picture / future
work". Rank the 8 hardest so I prepare those first.
```

## 10. The Tough-Question Rehearser
```
Ask me my hardest defense questions ONE AT A TIME. After each answer I give,
critique it: was it direct, did I concede appropriately, did I overclaim? Then give
a model answer. Start with: [PASTE a claim/limitation you'll probe].
```

## 11. The Defense Talk Builder
```
Outline my [20/30/45]-minute defense talk from [PASTE thesis summary + key figs].
Slide-by-slide: one message per slide, where each figure goes, the narrative arc
(problem → approach → findings → significance → future), and the 3 things the
committee must remember. Note slides to cut if I'm over time.
```

## 12. The Limitations Framer
```
Help me present my study's limitations honestly but confidently. My limitations:
[LIST]. For each: acknowledge it, state how it bounds (not invalidates) the
conclusion, and what a follow-up would do. Give me talk-ready phrasing that shows
maturity, not weakness.
```

## 13. The Elevator Pitch Set
```
Write my research pitch at 4 lengths: 1 sentence, 30 seconds, 2 minutes, and a
"why should a non-scientist care" version. Topic: [TOPIC]. Finding: [FINDING].
Significance: [WHY]. Natural spoken language, no jargon dumps.
```

## 14. The Slide-Text Tightener
```
My slide has too much text: [PASTE]. Cut it to headline + max 5 short bullets (or
suggest a visual instead). Give me the on-slide text and separate speaker notes for
what I actually say. Repeat for each slide I paste.
```

## 15. The Q&A Bridge Kit
```
Give me 8 professional "bridge" phrases for defense/conference Q&A: buying time,
admitting I don't know gracefully, handling a hostile question, redirecting to my
data, and clarifying a misunderstood question. Natural, not robotic.
```

# AREA 3 — SUPERVISOR & COLLABORATION (16–22)

## 16. The Advisor-Email Drafter
```
Draft a concise email to my [advisor/PI]. Goal: [ask for meeting / send draft /
report a problem / request a deadline extension / disagree with a suggestion].
Context: [SITUATION]. Under 150 words, respectful, clear ask, proposed next step.
Give a warmer and a more direct version.
```

## 17. The Meeting Prep Sheet
```
I have a supervision meeting on [DATE]. My progress: [WHAT I DID]. My blockers:
[BLOCKERS]. Decisions I need from them: [DECISIONS]. Build me a one-page agenda:
updates (brief), specific questions (prioritized), and decisions to reach. Include
what I'll do if we run out of time.
```

## 18. The Difficult-Conversation Planner
```
I need to raise [ISSUE — e.g. authorship, unrealistic expectations, lack of
feedback, a mistake I made] with my [advisor/collaborator]. Help me: frame it with
situation-behavior-impact, anticipate their likely response, and draft opening
lines that are honest and non-confrontational. Firm and professional.
```

## 19. The Authorship Clarifier
```
Help me think through authorship for [PROJECT]. Contributors and what they did:
[LIST]. Based on standard criteria (substantial contribution, drafting/revising,
approval, accountability), suggest a defensible author order and who's
acknowledged vs authored. Draft a neutral message to propose it. (Final call is a
human conversation.)
```

## 20. The Feedback Decoder
```
My supervisor gave this feedback: [PASTE]. Help me: (a) translate vague comments
into concrete actions, (b) identify what they actually care most about, (c) list
clarifying questions to ask, (d) draft a short reply confirming my plan.
```

## 21. The Collaboration Brief
```
I'm starting a collaboration with [WHO] on [WHAT]. Draft a short "working
agreement": shared goal, who does what, data/tool sharing, authorship expectations,
timeline, and check-in cadence. Diplomatic, sets expectations early without being
heavy-handed.
```

## 22. The Recommendation-Request Kit
```
Help me ask [PROFESSOR] for a recommendation letter for [OPPORTUNITY]. Draft: the
request email (respectful, gives them an easy out), and a "brag sheet" I'd attach —
bullet points on what I did with them, my strengths, and the specific points they
could highlight. Deadline: [DATE].
```

# AREA 4 — PRODUCTIVITY & FOCUS (23–30)

## 23. The Week Planner
```
You are my research productivity coach. This week's must-dos: [LIST]. Fixed
commitments: [MEETINGS/CLASSES]. My focus hours: [WHEN I WORK BEST]. Build a
time-blocked week: deep work on the hardest thing first, batched admin, buffer.
Protect my best hours for writing/analysis, not email.
```

## 24. The Overwhelm Triage
```
Brain-dump: [EVERYTHING ON MY PLATE]. Triage it: what's truly urgent AND important,
what's fake-urgent, what dies harmlessly if ignored, what I can delegate/defer.
Give me today's top 3 and permission-logic for dropping the rest.
```

## 25. The Deep-Work Session Designer
```
I have [HOURS] for deep work on [TASK]. Design the session: a specific outcome to
aim for, how to break it into 2–3 focused blocks with short breaks, what to
silence, and a "if I get stuck" fallback. End with a definition of done.
```

## 26. The Procrastination Unblocker
```
I've been avoiding [TASK] because [REASON — fear, unclear, boring, too big].
Diagnose the real block and give me the smallest possible first step (5 minutes),
plus a way to make the task less aversive. No generic "just do it" advice.
```

## 27. The Reading-Load Manager
```
I have [N] papers to read for [PURPOSE] by [DATE]. Help me triage: which to read
deeply, skim, or just cite; a fast triage method (abstract → figures → decide); and
a schedule. Give me a 3-question filter to decide a paper's depth in 2 minutes.
```

## 28. The Note System Designer
```
Design a simple literature-note system I'll actually maintain, given I use
[TOOL — Zotero/Notion/Obsidian/paper]. Include: a per-paper note template (5
fields), how to tag for retrieval, and a weekly 15-minute upkeep routine. Keep it
low-friction.
```

## 29. The Context-Switch Reducer
```
My week is fragmented across [LIST PROJECTS/DUTIES]. Suggest a batching and
theming scheme (e.g. writing days vs lab days vs admin blocks) that fits my
constraints [CONSTRAINTS], plus rules to protect focus. Show a sample week.
```

## 30. The Weekly Review Ritual
```
Every Friday, walk me through a 10-minute research review. Ask me: what moved
forward, what stalled and why, what I avoided, next week's ONE priority, and one
thing to stop doing. Then summarize into 5 bullets I can compare week to week.
```

# AREA 5 — CAREER & APPLICATIONS (31–38)

## 31. The Academic CV Auditor
```
You are a hiring-committee member in [FIELD]. Review my CV: [PASTE]. Tell me: what
stands out, what's buried, what's missing for [TARGET — PhD/postdoc/industry], and
the top 5 edits to make it stronger. Be specific and honest.
```

## 32. The Cover-Letter / Motivation-Letter Writer
```
Write a motivation letter for [POSITION/PROGRAM] at [PLACE]. My background: [PASTE
CV HIGHLIGHTS]. Why me + why them + what I'd contribute, tied to their actual work
[WHAT THEY DO]. One page, specific, no generic flattery. Show fit, not desperation.
```

## 33. The Research-Statement Builder
```
Draft a research statement for [ACADEMIC APPLICATION]. Structure: my research
vision, what I've done (2–3 threads with impact), what I'll do next (fundable
directions), and why it fits [INSTITUTION]. From my inputs: [PASTE]. Ambitious but
credible; no jargon walls.
```

## 34. The Industry-Translation Kit
```
I'm a [FIELD] researcher considering industry roles in [SECTOR/ROLE]. Translate my
academic experience into industry language: map my skills [PASTE] to what the role
values, rewrite 5 CV bullets in results-oriented terms, and list 3 transferable
strengths I'm underselling.
```

## 35. The Interview Prep (academic or industry)
```
Prepare me for a [academic job talk / postdoc / industry] interview for [ROLE].
Give 12 likely questions (research, fit, collaboration, failure, future), what a
strong answer contains, and 5 smart questions I should ask them. Then run 3 of the
hardest with me one at a time.
```

## 36. The Networking-Message Writer
```
Draft a short, non-cringe outreach message to [WHO — a researcher whose work I
admire / potential postdoc advisor / conference contact]. Goal: [chat / ask about
their lab / follow up after meeting]. Specific about why them, easy to say yes to,
under 120 words. Give a LinkedIn and an email version.
```

## 37. The Fellowship-Application Strategist
```
I'm applying for [FELLOWSHIP/GRANT]. Given the criteria [PASTE or DESCRIBE] and my
profile [PASTE], tell me: how well I fit, my strongest angles to emphasize, my
weak spots and how to mitigate them, and a section-by-section plan for the
application. Honest odds and where to focus effort.
```

## 38. The Rejection Reframe + Next Step
```
I got rejected from [OPPORTUNITY]. Feedback (if any): [PASTE]. Help me: extract any
actionable signal, separate it from noise, decide whether to ask for feedback, and
plan the next 2 concrete applications/actions. Constructive, not consoling-fluff.
```

# AREA 6 — TEACHING & MENTORING (39–44)

## 39. The Lesson/Lab Planner
```
Plan a [DURATION] [lecture / lab / seminar] on [TOPIC] for [LEVEL — undergrad/
grad]. Learning objectives (3), a timed structure, an activity or problem to keep
them engaged, common misconceptions to pre-empt, and a quick way to check
understanding at the end.
```

## 40. The Explainer-at-Any-Level
```
Explain "[CONCEPT]" so I can teach it. Give: a hook to open with, the core idea in
plain terms, a worked example, the 3 misconceptions students have, and 2 analogies.
Then 4 check-your-understanding questions with answers. Accurate; flag anything
simplified.
```

## 41. The Student-Feedback Writer
```
Help me give constructive feedback on a student's [draft/report/presentation].
Their work: [SUMMARIZE / PASTE]. Structure: what's working (specific), 2–3
priority improvements with how-to, and an encouraging close. Kind, clear,
actionable — not a list of everything wrong.
```

## 42. The Rubric Builder
```
Create a grading rubric for [ASSIGNMENT] at [LEVEL]. 4–6 criteria with clear
level descriptors (excellent/good/needs work/poor), weightings, and a one-line
"what I'm really assessing" note per criterion. Fair, transparent, fast to apply.
```

## 43. The Mentee-Question Answerer
```
My [B.Sc./M.Sc.] student asked: [QUESTION]. Help me answer in a way that guides
rather than just gives the answer: a Socratic version (questions to lead them),
the direct answer if needed, and a resource to point them to. Supportive mentor
tone.
```

## 44. The Office-Hours FAQ
```
Generate answers to the 10 questions students most often ask about [COURSE/TOPIC].
Concise, accurate, and where relevant, point to where in the material to look.
I'll post these to save repeat questions.
```

# AREA 7 — SCIENTIFIC WRITING CRAFT (45–50)

## 45. The Sentence Surgeon
```
Tighten this academic paragraph without losing meaning or nuance: [PASTE]. Cut
hedging clutter, nominalizations, and redundancy; prefer active voice where the
field allows; keep necessary precision. Show the revised version and a one-line
note on what you changed.
```

## 46. The Jargon Calibrator
```
My audience is [SPECIALIST / ADJACENT FIELD / GENERAL]. Adjust this text's
technical level accordingly: [PASTE]. Define or replace jargon as needed, keep the
science correct, and flag any term I must keep for precision. Give the adjusted
version.
```

## 47. The Flow Fixer
```
This section reads choppy/disconnected: [PASTE]. Improve the logical flow: add
transitions, reorder sentences if needed, and make each paragraph have one clear
point with a topic sentence. Don't change the claims or add content. Show the
revised version.
```

## 48. The ESL Polish (meaning-preserving)
```
Polish my English for a journal submission — I'm a non-native speaker. Fix grammar,
articles, prepositions, and awkward phrasing while KEEPING my meaning and voice.
Do not change technical claims or numbers. Mark anywhere the original was
ambiguous so I can clarify.
Text: [PASTE]
```

## 49. The Precision Checker
```
Review this passage for scientific precision: [PASTE]. Flag overclaims ("proves",
"always"), vague quantifiers ("many", "significant" used loosely), causal language
not supported by design, and missing units/uncertainties. Suggest precise
replacements. Don't soften genuinely strong claims.
```

## 50. The Consistent-Terminology Enforcer
```
I sometimes use different terms for the same thing (e.g. [EXAMPLES]). Given my
text [PASTE], build a mini glossary of preferred terms, flag every inconsistent
usage with location, and give the standardized version. Keep field conventions.
```

# AREA 8 — DATA, CODE & TOOLS (51–53)

## 51. The Analysis-Plan Writer
```
Before I touch the data, help me pre-register my analysis for [STUDY]. Design:
[DESCRIBE]. Specify: hypotheses, variables, the exact statistical tests and why,
assumption checks, how I'll handle outliers/missing data, and my stopping rule.
Output a clean analysis plan. I'll run and verify it.
```

## 52. The Code-Skeleton Generator
```
Write a commented [Python / R] script skeleton to [GOAL — e.g. load and clean my
dataset, run [ANALYSIS], and produce publication figures]. My data:
[COLUMNS/FORMAT]. Include structure, key functions, and TODO markers where I add
specifics. I will run, test and validate it myself.
```

## 53. The Debugging Partner
```
My [Python/R] code throws this error: [PASTE ERROR + RELEVANT CODE]. Explain what's
going wrong in plain terms, the most likely cause, and 2 fixes to try. Then note
how to prevent this class of bug. Don't rewrite everything — target the problem.
```

# AREA 9 — WELLBEING & THE LONG GAME (54–55)

## 54. The Impostor-Syndrome Reframe
```
I feel behind/like a fraud because [WHAT'S TRIGGERING IT]. Give me honest
perspective: what's normal at my stage [STAGE + TIME IN], what's visible vs
invisible in peers' success, and refocus me on the 3 inputs I control this week.
Direct and grounded, not toxic positivity. (Not a substitute for real support if
I'm struggling.)
```

## 55. The Sustainable-Pace Planner
```
Help me design a sustainable research week that protects my health. My current
pattern: [DESCRIBE]. Energy drains and boundaries I need: [LIST]. Suggest realistic
changes: hard stops, one recovery habit, and how to say no to [OVER-COMMITMENT].
Small and doable, not a life overhaul.
```

# ⚙️ THE 5 RESEARCH WORKFLOWS
Chains of prompts that form complete systems. Run the steps in one conversation so the AI keeps context.

## Workflow A — Blank Page to First Draft (a paper in ~2 weeks of focused work)
1. **Map:** Publish Faster #9 (Outline Architect).
2. **Frame:** Publish Faster #10 (Intro Funnel) + #11 (Methods Cleaner).
3. **Report:** #12 (Results Narrator) → #21 (Figure Captions).
4. **Interpret:** #13 (Discussion Builder).
5. **Package:** #14 (Abstract) + #6 (Title) + #15 (Cover Letter).
6. **Self-review:** #31 (Reviewer 2 self-review) before you send it to co-authors.

## Workflow B — The Revise-and-Resubmit System
1. #34 (Decision-Letter Interpreter) — read the real signal.
2. #32 (Weakness Pre-empter) — map every comment to an action.
3. #29 (Reviewer Rebuttal Engine) — draft each response.
4. #30 (Tone Softener) on anything that reads defensive.
5. #33 (Revision Change-Log) for the editor.
6. #36 (Consistency Sweep) on the final manuscript.

## Workflow C — The Thesis Endgame
1. Academic OS #1 (Thesis Roadmap) — reverse timeline.
2. #8 ("Am I Done?" gap check) — find holes early.
3. #5 (Consistency & Formatting Auditor) chapter by chapter.
4. #6 (Abstract & Summary Set).
5. Defense prep: #9 (Question Bank) → #10 (Rehearser) → #11 (Defense Talk).

## Workflow D — The Weekly Research OS (30 min/week)
1. Monday: #23 (Week Planner).
2. Daily: #25 (Deep-Work Session Designer) for your hardest task.
3. Midweek stall: #24 (Overwhelm Triage) or #26 (Procrastination Unblocker).
4. Friday: #30 (Weekly Review Ritual).
5. Monthly: #4 (Thesis-to-Papers Planner) to keep the big picture.

## Workflow E — The Job-Market Campaign
1. #31 (CV Auditor) — fix the CV first.
2. #33 (Research Statement) + #32 (Motivation Letter) per application.
3. #37 (Fellowship Strategist) or #34 (Industry Translation) depending on path.
4. #35 (Interview Prep) once you get bites.
5. #38 (Rejection Reframe) to keep momentum between rounds.
