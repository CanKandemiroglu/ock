# DEPT 1 — STRATEGY & PLANNING (1–8)

## 1. The One-Page Business Plan
```
You are a startup advisor. Business idea: [IDEA]. Build a one-page plan:
problem, customer, solution, unfair advantage, revenue model, channels,
costs, key metrics, and the single riskiest assumption with a cheap way to
test it this week.
```

## 2. The Riskiest Assumption Test
```
My business: [BUSINESS]. List the 5 assumptions my success depends on.
Rank by (impact if wrong × likelihood of being wrong). For the top one,
design a test I can run in 7 days for under $100, with a clear pass/fail
threshold.
```

## 3. The SWOT That's Actually Useful
```
Run a SWOT for [BUSINESS]. For each item, add the "so what": the specific
action it implies. End with the 3 moves that convert my biggest strength
against my biggest opportunity.
```

## 4. The Quarterly OKR Setter
```
You are a planning coach. Business: [BUSINESS]. Annual goal: [GOAL].
Draft Q[N] OKRs: 1 objective, 3 measurable key results, and weekly
leading indicators I can check every Friday in under 5 minutes. Flag any
key result that measures activity instead of outcome.
```

## 5. The Pivot Evaluator
```
My business: [BUSINESS]. Current traction: [NUMBERS/SITUATION]. I'm
considering: [PIVOT IDEA]. Steelman both paths — the strongest case for
staying and the strongest case for pivoting. What evidence would settle it?
Give me a 2-week plan to gather that evidence.
```

## 6. The Revenue Stream Auditor
```
Business: [BUSINESS]. Current revenue streams: [LIST + rough %].
Suggest 5 additional streams ranked by (fit with existing assets × effort
to launch). For the top pick: 30-day launch plan and realistic first-month
revenue range.
```

## 7. The Annual Vision Backcast
```
It's [DATE +1 YEAR] and my business hit [DREAM OUTCOME]. Work backwards:
what must have happened by month 9, 6, 3, and 1 for that to be true?
Identify the first domino — the one thing this month that makes everything
downstream easier.
```

## 8. The Decision Journal
```
Decision I'm facing: [DECISION]. Options: [OPTIONS]. Walk me through:
what I'm optimizing for, reversibility of each option, base rates (how do
choices like this usually go?), what I'd advise a friend, and pre-mortem —
it's 6 months later and this failed: why? End with a recommendation and a
review date.
```

# DEPT 2 — FINANCE & PRICING (9–15)

## 9. The Profit Leak Finder
```
You are a small-business CFO. My monthly numbers: revenue [X], costs
[LIST ROUGHLY]. Find likely profit leaks: subscriptions, underpricing, low-
margin offerings, manual time sinks. Rank fixes by monthly dollars
recovered per hour of effort to fix.
```

## 10. The Cash Flow Forecaster
```
Build me a simple 13-week cash flow template. Starting cash: [AMOUNT].
Predictable income: [LIST]. Predictable expenses: [LIST]. Show the weekly
math, flag any week I go negative, and give 3 moves to fix crunch weeks
(collections, terms, timing shifts).
```

## 11. The Break-Even Calculator
```
Product: [PRODUCT]. Price: [PRICE]. Unit/delivery cost: [COST]. Fixed
monthly costs: [AMOUNT]. Calculate break-even units and revenue, show the
formula, then model 3 scenarios: 10% price raise, 10% cost cut, and both.
Which lever matters more for me and why?
```

## 12. The Rate Calculator (Services)
```
I want to earn [TARGET INCOME]/year working [HOURS]/week with [WEEKS OFF]
weeks off. Account for non-billable time (~40%), taxes and expenses
[ESTIMATE %]. Calculate my minimum hourly rate and day rate, then suggest
3 packaged prices so I sell outcomes, not hours.
```

## 13. The Expense Justifier
```
I'm considering spending [AMOUNT] on [PURCHASE] for [BUSINESS].
Give me the honest analysis: payback period, what must be true to ROI
positive, cheaper ways to get 80% of the value, and the "wait 30 days"
test. Am I buying a tool or buying the feeling of progress?
```

## 14. The Price Objection Math
```
My offer: [OFFER + PRICE]. Customer's alternative: doing nothing or
[ALTERNATIVE]. Build the cost-of-inaction case: what staying put costs
them monthly in money, time and stress. Turn it into one paragraph of
sales copy and one simple visual comparison I can describe.
```

## 15. The Tax Season Prep Checklist
```
I run [BUSINESS TYPE] in [COUNTRY/STATE]. Create my tax-prep checklist:
documents to gather, common deductions businesses like mine miss,
quarterly deadlines to calendar, and the 5 questions to ask my accountant.
(General info — I'll verify with a professional.)
```

# DEPT 3 — OPERATIONS & PRODUCTIVITY (16–23)

## 16. The Process Documenter
```
I'll describe how I do [TASK]: [ROUGH DESCRIPTION]. Turn it into a clean
SOP: purpose, when to run it, numbered steps with decision points, common
mistakes, and definition of done. Write it so a new hire could execute
without asking me anything.
```

## 17. The Automation Auditor
```
Here's my typical week: [DESCRIBE RECURRING TASKS]. Categorize each:
automate (suggest the tool), delegate, batch, or delete. Estimate hours
saved per month for each change and give me the top 3 to implement this
week with setup steps.
```

## 18. The Perfect Week Designer
```
Design my ideal work week. Constraints: [HOURS AVAILABLE, FIXED
COMMITMENTS, ENERGY PATTERNS e.g. "sharpest 8–11am"]. Business priorities:
[TOP 3]. Time-block a repeatable weekly template: deep work, admin
batching, marketing, buffer. Protect my highest-energy hours for the
highest-leverage work.
```

## 19. The Meeting Eliminator
```
Recurring meetings/calls I hold: [LIST with purpose + length]. For each:
kill it, shorten it, make it async (give the exact async format), or keep
it. Write the message announcing changes without making anyone defensive.
```

## 20. The Inbox Zero System
```
Design an email management system for me: [DESCRIBE VOLUME + TYPES OF
EMAIL]. Include: folder/label structure, the 4D rule applied to my
categories, 5 canned responses for my most common emails (draft them),
and a 2x/day processing routine under 30 minutes total.
```

## 21. The Tool Stack Rationalizer
```
My current tools: [LIST TOOLS + MONTHLY COSTS]. Business: [BUSINESS].
Find overlap, suggest consolidations, flag what a spreadsheet could
replace, and design the leanest stack. Show current vs proposed monthly
total.
```

## 22. The Bottleneck Breaker
```
Theory of constraints analysis. My business process: [DESCRIBE FLOW FROM
LEAD TO DELIVERED]. Volume at each stage: [ROUGH NUMBERS]. Identify the
constraint, explain why fixing anything else is wasted effort right now,
and give 3 ways to elevate the constraint this month.
```

## 23. The Quarterly Cleanup
```
Guide me through a business spring-clean: offers to retire, clients to
gracefully release (draft the message), subscriptions to cancel, files/
systems to organize, and metrics to stop tracking. Format as a half-day
checklist with time estimates.
```

# DEPT 4 — CUSTOMER SERVICE (24–30)

## 24. The Support Macro Library
```
Business: [BUSINESS]. Write 10 support response templates: order/project
status, refund request (approve), refund request (decline, with grace),
shipping/delivery delay, "how do I..." pointer, angry customer de-
escalation, feature request thanks, praise response, billing question,
and "we made a mistake" ownership. Warm, human, under 100 words each.
```

## 25. The Refund Policy Writer
```
Draft a refund policy for [BUSINESS + WHAT YOU SELL]. Requirements:
protects me from abuse, feels generous to honest customers, plain English
(no legalese), under 200 words. Then give the internal decision tree for
edge cases.
```

## 26. The Angry Customer Defuser
```
A customer wrote: [PASTE MESSAGE]. Context: [WHAT HAPPENED]. Draft a
response that: acknowledges specifically (not generically), takes
ownership where deserved, states exactly what I'll do and by when, and
offers a make-good. No over-apologizing, no policy-hiding. Then tell me
if this customer is worth saving or should be gracefully refunded away.
```

## 27. The Feedback Loop Builder
```
Design a customer feedback system for [BUSINESS]: the 3-question post-
purchase survey (draft it), when to send, how to spot patterns monthly,
and the "close the loop" message when I ship something a customer asked
for. Keep total customer effort under 2 minutes.
```

## 28. The Onboarding Experience
```
Map the first 30 days for a new customer of [OFFER]. Goal: they get a win
fast and never wonder "what now?". Deliver: welcome message (draft),
quick-win milestone in week 1, check-in cadence with draft messages, and
the moment to ask for a referral or review.
```

## 29. The Churn Saver
```
A customer wants to cancel [SUBSCRIPTION/SERVICE]. Reason given: [REASON].
Write the save flow: acknowledge without friction, one targeted counter-
offer matched to their reason (pause, downgrade, fix), and a graceful
goodbye that leaves the door open. Never make leaving hard — make staying
attractive.
```

## 30. The VIP Program
```
Design a simple VIP/loyalty system for [BUSINESS] without special
software: how customers qualify, 3 perks that cost me little but feel
premium, the surprise-and-delight touch, and the message telling someone
they've been upgraded.
```

# DEPT 5 — HIRING & DELEGATION (31–36)

## 31. The First Hire Decider
```
Business: [BUSINESS]. Revenue: [AMOUNT]. My weekly tasks: [LIST].
What should my first hire/contractor take over? Analyze by: what only I
can do, what I'm bad at, what's cheapest to buy. Recommend the role,
hours, realistic rate, and the 90-day ROI case.
```

## 32. The Job Post That Filters
```
Write a job post for [ROLE] at [BUSINESS]. Include: what they'll actually
do (specific week-one tasks), who thrives here / who won't, pay range
[RANGE], and an application instruction that filters for attention to
detail (hidden instruction technique). Sound like a human wrote it.
```

## 33. The Interview Kit
```
Create an interview kit for [ROLE]: 8 questions — 3 behavioral (past
specifics, not hypotheticals), 2 skill probes, 2 judgment scenarios from
my actual business [DESCRIBE A REAL SITUATION], 1 values fit. Include
what good and bad answers sound like, and a simple scorecard.
```

## 34. The Delegation Brief
```
I'm handing off [TASK] to [PERSON/VA]. Write the delegation brief:
outcome (what done looks like), authority level (decide vs recommend vs
ask), resources, deadline, check-in points, and the 3 mistakes to avoid.
Format so I can reuse it as a template for every handoff.
```

## 35. The Freelancer Vetting System
```
I'm hiring a freelance [SKILL] for [PROJECT]. Give me: 5 red flags in
proposals, a small paid test task design (fair, revealing, under $50),
the 5 questions for the intro call, and a simple contract-terms checklist
(scope, revisions, IP, kill fee).
```

## 36. The Performance Conversation
```
I need to talk to [ROLE] about [ISSUE]. Prepare me: the SBI framing
(situation-behavior-impact) in exact words, likely responses and my
replies, the clear ask going forward, and the follow-up message
documenting what we agreed. Firm, kind, no sandwich technique.
```

# DEPT 8 — FOUNDER EFFECTIVENESS (48–55)

## 48. The Weekly CEO Review
```
Every Friday, run me through my CEO review. Ask me: wins, misses, numbers
vs targets [MY 3 KEY METRICS], what consumed time vs created value, what
I avoided, next week's ONE priority. Then summarize into 5 bullet points
```

## 49. The Overwhelm Triage
```
Everything on my plate: [BRAIN-DUMP EVERYTHING]. Triage it: what's
actually urgent AND important, what's fake-urgent, what dies if ignored
(nothing usually), what to delegate/defer. Give me today's 3-item list
and permission logic for ignoring the rest.
```

## 50. The Decision Fatigue Killer
```
Recurring decisions that drain me: [LIST e.g. content topics, pricing
exceptions, which leads to pursue]. Turn each into a personal policy/
```

## 51. The Skill Gap Analyzer
```
My business goal: [GOAL]. My current skills: [HONEST LIST]. Identify the
1–2 skill gaps most limiting the goal, whether to learn vs hire for

```

## 52. The Comparison Trap Breaker
```
I'm feeling behind because [WHAT'S TRIGGERING IT]. Give me perspective:
what's actually visible vs invisible in competitors' success, my base
rate progress [MY SITUATION + TIME IN BUSINESS], and refocus me on the
```

## 53. The Energy Audit

```
Walk me through an energy audit: I'll list my regular activities and
```

# ⚙️ THE 5 WORKFLOWS
Multi-step systems that chain prompts. Run the steps in one conversation so the AI keeps context.

## Workflow A — The Content Engine (weekly, ~45 min)
1. **Mine:** Run #5 from Marketing Machine (Customer Language Miner) once per month; keep the output.
2. **Plan:** Run Marketing Machine #10 (Content Calendar) pasting the customer language in.
3. **Draft:** For each planned post, run #11 or #12 (Carousel Builder / Storyteller).
4. **Repurpose:** Feed the best post into #40 (Content Repurposer).
5. **Review:** End the week with the Meta-Prompt on your weakest draft.

## Workflow B — The Launch System (one-time, spread over 2 weeks)
1. Validate with #37 (Idea Validator) → kill or continue.
2. Scope with #38 (MVP Scoper).
3. Build the offer with Marketing Machine #6 (Offer Stack Designer).
4. Write the page with Marketing Machine #44 (Sales Page Skeleton).
5. Write emails with Marketing Machine #23 (Launch Sequence).
6. Post-launch: run #48 (Weekly CEO Review) and iterate.

## Workflow C — The Client Machine (for service businesses)
1. Marketing Machine #28 (Cold Email) or #43 (Guest Pitch) → conversations.
2. #46 (Discovery Call Frame) → run the call.
3. #47 (Proposal Template) → send same day.
4. #34 (Delegation Brief) → deliver with help.
5. #28 Onboarding + #27 Feedback Loop → turn delivery into referrals via #49 Referral Engine (Marketing Machine).

## Workflow D — The Monthly Money Review (~60 min/month)
1. #9 (Profit Leak Finder) with fresh numbers.
2. #10 (Cash Flow Forecaster) — update the 13 weeks.
3. Marketing Machine #50 (Monthly Marketing Review).
4. #4 (OKR check) — are key results moving?
5. Output: 3 priorities for next month. Calendar them immediately.

## Workflow E — The Firefight Protocol (when things go wrong)
1. #49 (Overwhelm Triage) — brain-dump everything first.
2. If it's a customer issue: #26 (Angry Customer Defuser).
3. If it's a cash issue: #10 + #45 (Late Payment Collector).
4. If it's a you issue: #53 (Energy Audit).
5. Afterwards: #8 (Decision Journal) — capture the lesson.
