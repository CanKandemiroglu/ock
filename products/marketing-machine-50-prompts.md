# 🚀 Marketing Machine — 50 Battle-Tested Marketing Prompts

**Turn ChatGPT/Claude into your marketing department.**
Replace anything in `[BRACKETS]`. Every prompt includes role + context + constraints + output format — that's why they outperform free one-liner prompts.

**How to get the best results:**
1. Fill brackets with painful specificity (audience, price, platform).
2. If output misses, reply: *"Good, but make it more [specific/punchy/casual] and fix [X]."* Iteration is the skill.
3. Save your best outputs — feed them back later with *"match this voice."*

# PART 1 — STRATEGY & POSITIONING (1–8)

## 1. The Positioning Statement Builder
```
You are a positioning strategist (April Dunford school). My business: [BUSINESS].
Customers: [AUDIENCE]. Competitors: [ALTERNATIVES THEY'D USE INSTEAD].
Work through: 1) competitive alternatives, 2) what we do they can't,
3) the value that capability creates, 4) who cares most about that value,
5) the market category to anchor in. End with a one-sentence positioning
statement and a homepage headline based on it.
```

## 2. The Unique Mechanism Finder
```
You are a direct-response strategist. My offer: [OFFER]. Everyone in my niche
promises [COMMON PROMISE]. Find the "unique mechanism" in how I deliver results:
interview me with 5 questions about my process, then (after I answer) name the
mechanism something memorable and write 3 headlines built around it.
```

## 3. The Category Kingmaker
```
My business: [BUSINESS]. Instead of competing in the crowded category of
[EXISTING CATEGORY], suggest 3 ways to niche down or reframe so I'm the obvious
#1 choice for a specific someone (e.g. "accountant" → "accountant for Etsy
sellers"). For each: the niche, why it's underserved, and the tagline.
```

## 4. The Message-Market Fit Test
```
You are a copy chief. Here is my current homepage/profile text: [PASTE TEXT].
My ideal customer: [AUDIENCE]. Grade it 1–10 on: clarity in 5 seconds, speaking
to a real pain, differentiation, and call-to-action strength. Then rewrite it to
a 10, and explain each change in one line.
```

## 5. The Customer Language Miner
```
You are a voice-of-customer researcher. My product: [PRODUCT] for [AUDIENCE].
Generate the exact phrases customers would use: 10 ways they'd describe the
problem in their own words, 10 ways they'd describe the dream outcome, and 5
suspicious/skeptical thoughts they'd have about offers like mine. I'll use these
verbatim in copy.
```

## 6. The Offer Stack Designer
```
You are an offer strategist using the value equation (dream outcome × likelihood
of success ÷ time × effort). My core offer: [OFFER + PRICE]. Design an offer
stack: core + 3 bonuses that remove specific obstacles (name each obstacle),
a risk-reversal guarantee, and honest urgency. Write the final offer as a
bulleted "here's everything you get" block with value anchoring.
```

## 7. The Funnel Architect
```
You are a funnel strategist. My business: [BUSINESS]. Price point: [PRICE].
Audience awareness level: [never heard of us / knows the problem / compares
options]. Design the simplest funnel that fits: traffic source → lead magnet →
nurture → offer. One page per step with its single job, plus the #1 metric per
step and realistic benchmark conversion rates.
```

## 8. The 90-Day Marketing Roadmap
```
You are a fractional CMO. Business: [BUSINESS]. Budget: [BUDGET]/month.
Time: [HOURS]/week. Goal: [GOAL, e.g. first 50 customers]. Build a 90-day
roadmap: monthly themes, weekly actions (max 3), what to measure, and explicit
"do NOT do" list to protect focus. Format as a table.
```

# PART 2 — SOCIAL MEDIA (9–18)

## 9. The Hook Factory
```
Write 20 scroll-stopping first lines (hooks) for [PLATFORM] posts about [TOPIC]
for [AUDIENCE]. Use these patterns: contrarian take, specific number/result,
call-out question, "I was wrong about...", curiosity gap, and mistake warning.
Label each pattern. No clickbait that the post can't cash.
```

## 10. The 30-Day Content Calendar
```
You are a content strategist. Create a 30-day content calendar for [BUSINESS]
on [PLATFORM]. Weekly rhythm: [e.g. 3 posts/week]. Rotate pillars: educate,
entertain, build trust, sell (80/20 value-to-pitch ratio). Table format: day,
pillar, topic, hook line, CTA. Make topics specific enough to write from
directly.
```

## 11. The Carousel/Thread Builder
```
Turn this idea into a [carousel / thread]: [TOPIC OR PASTE ROUGH NOTES].
Structure: slide 1 = hook with a bold claim or question, slides 2–7 = one idea
per slide (max 20 words each), final slide = summary + CTA to [ACTION].
Write it so each slide makes them need the next one.
```

## 12. The Storyteller
```
You are a story coach. Raw material: [DESCRIBE A CUSTOMER WIN, FOUNDER MOMENT,
OR FAILURE]. Write it as a 150-word social post using: hook → struggle →
turning point → result → lesson → soft CTA. First person, conversational,
no "and that's when I realized" clichés.
```

## 13. The Comment-to-Customer Converter
```
Someone commented [PASTE COMMENT] on my post about [TOPIC]. Write 3 reply
options: one purely helpful, one helpful + soft invite to DM/resource, one witty
but professional. Never pushy — the goal is the relationship, not the pitch.
```

## 14. The Reel/Short Script Machine
```
Write 5 scripts for 30-second vertical videos for [BUSINESS]. Each: spoken hook
(first 2 seconds, must stop the scroll), 3 fast value points, on-screen text
suggestions, and end CTA. Topics: the 5 questions my customers ask most:
[LIST THEM, or ask me first].
```

## 15. The Engagement Bait (Ethical Edition)
```
Write 10 conversation-starter posts for [BUSINESS] that get real comments
without cringe engagement bait. Formats: this-or-that, fill-in-the-blank,
unpopular opinion poll, "what would you do", and caption-this. Each must be
genuinely fun for [AUDIENCE] AND relevant to what I sell.
```

## 16. The Profile Optimizer
```
You are a [PLATFORM] growth expert. My bio currently says: [PASTE BIO].
My business: [BUSINESS]. Goal: [FOLLOWERS / LEADS / SALES]. Rewrite my profile:
name field (searchable keywords), bio (who I help + how + proof + CTA), and
pinned-content strategy. 3 variants: professional, friendly, bold.
```

## 17. The Trend Hijacker
```
Current trend/news in my space: [DESCRIBE TREND]. My business: [BUSINESS].
Give me 5 angles to ride this trend that add real value (not just noise):
a hot take, a how-to application, a beginner explainer, a caution/counterpoint,
and a behind-the-scenes. Draft the strongest one as a full post.
```

## 18. The Community Builder
```
You are a community strategist. I want [PLATFORM GROUP / DISCORD / NEWSLETTER
COMMUNITY] for [AUDIENCE]. Design: the community's one-line promise, 3 recurring
weekly rituals (e.g. wins Wednesday), onboarding message for new members, and
5 discussion starters for week one.
```

# PART 3 — EMAIL MARKETING (19–28)

## 19. The Welcome Sequence
```
You are an email strategist. Write a 5-email welcome sequence for people who
signed up for [LEAD MAGNET] from [BUSINESS]. Email 1: deliver + quick win.
Email 2: my story + why I do this. Email 3: best free resource + belief shift.
Email 4: case study/social proof. Email 5: first offer with deadline.
Subject lines under 6 words. Each email under 200 words.
```

## 20. The Subject Line Splitter
```
Write 15 subject lines for an email about [EMAIL TOPIC] to [AUDIENCE].
5 curiosity-based, 5 benefit-based, 5 pattern-interrupt/weird. Max 45
characters each. Then pick the 2 you'd A/B test and explain the psychology.
```

## 21. The Newsletter Template
```
Create a repeatable weekly newsletter format for [BUSINESS] that takes under
60 minutes to write. Sections: one big idea (150 words), one quick tip, one
thing I found (curation), one soft plug. Write a complete example issue about
[TOPIC] in my voice: [DESCRIBE VOICE or paste a writing sample].
```

## 22. The Cart Abandoner / Ghost Reviver
```
Write a 3-email sequence for [leads who went quiet / carts abandoned] for
[OFFER]. Email 1 (day 1): friendly check-in + remove friction. Email 2 (day 3):
handle the most likely objection with proof. Email 3 (day 5): honest last-call
with deadline. Human tone, zero guilt-tripping.
```

## 23. The Launch Sequence
```
You are a launch copywriter. I'm launching [OFFER] on [DATE] to my list of
[SIZE/DESCRIPTION]. Write the 6-email launch arc: tease, open, value+proof,
objections FAQ, 24-hour warning, final hours. Give each email: subject, goal,
outline, and the full copy for emails 2 and 6.
```

## 24. The Sales Email Rewriter
```
Here's my draft email: [PASTE DRAFT]. Rewrite it 3 ways: (a) shorter and
punchier (half the length), (b) story-led, (c) blunt/no-fluff "here's the deal"
style. Keep my offer and links intact. Tell me which fits [AUDIENCE] best.
```

## 25. The Re-Engagement Winback
```
My email list hasn't heard from me in [TIME]. Write the "I've been gone" email
that wins them back: honest about the gap (no over-apologizing), immediate
value, what to expect from now on, and a one-click way to opt out guilt-free.
Under 150 words.
```

## 26. The Promo Calendar
```
Plan 12 months of email promotions for [BUSINESS]. Mix: 4 core-offer pushes,
seasonal angles relevant to [NICHE/AUDIENCE], 2 flash promos, and value-only
months to rest the list. Table: month, campaign, angle, emails needed.
```

## 27. The Testimonial Harvester
```
Write emails to get testimonials from customers of [BUSINESS]: (a) the ask —
makes it a 3-minute task with 3 guiding questions that produce specific,
results-focused answers, (b) the thank-you + permission to publish,
(c) a version that asks for a video instead. Friendly, low pressure.
```

## 28. The Deliverability-Safe Cold Email
```
You are a B2B outbound expert. My offer: [OFFER] for [TARGET COMPANY TYPE].
Write a 3-touch cold email sequence: under 90 words each, one specific
personalization slot per email, one clear low-friction ask (reply, not "book a
call" on touch 1), no spam-trigger words. Include 5 first-line personalization
examples.
```

# PART 4 — PAID ADS (29–36)

## 29. The Facebook/IG Ad Set
```
You are a paid social buyer ($10M+ spend). Product: [PRODUCT + PRICE].
Audience: [AUDIENCE]. Write 5 ad variants: 2 problem-agitate-solve, 1 customer
story/UGC style script, 1 "us vs the old way" comparison, 1 straight offer.
Each: hook (first 5 words critical), body <90 words, CTA, and a creative
suggestion (image/video concept).
```

## 30. The Google Search Ad Builder
```
You are a Google Ads specialist. Business: [BUSINESS]. Target keywords:
[KEYWORDS or "suggest 10 buyer-intent keywords first"]. Write 2 Responsive
Search Ads: 10 headlines (≤30 chars) and 4 descriptions (≤90 chars) each.
Cover: benefit, social proof, offer, urgency, and keyword-match headlines.
Then list 10 negative keywords to save my budget.
```

## 31. The Ad Angle Brainstorm
```
Generate 10 distinct advertising angles for [PRODUCT]. For each: the angle name,
the target emotion, the hook line, and which audience segment it fits.
Include: before/after, enemy/villain (the old way), speed, status, fear of
missing out, insider secret, contrarian, and social proof angles.
```

## 32. The Landing Page Copy
```
You are a CRO copywriter. Write landing page copy for [OFFER] targeted at
traffic from [AD/SOURCE]. Sections: headline + subhead (match the ad's promise),
3 benefit blocks, how-it-works (3 steps), social proof section (I'll insert
testimonials), FAQ (5 objections), and final CTA section. Punchy, scannable,
7th-grade reading level.
```

## 33. The Ad Diagnostician
```
My ad results: [PASTE METRICS: spend, impressions, CTR, CPC, conversions].
Product: [PRODUCT + PRICE]. Diagnose the funnel: is the problem the ad
(CTR), the landing page (conversion rate), or the offer? Give the benchmark
ranges, the most likely culprit, and the 3 highest-impact fixes in order.
```

## 34. The Retargeting Sequence
```
Design a retargeting campaign for [BUSINESS]. Segments: site visitors who
bounced, product/sales-page viewers, cart abandoners. For each: the message
angle, one ad copy variant, and frequency cap advice. Ads must feel like
helpful reminders, not stalking.
```

## 35. The UGC Brief
```
Write a creator brief for a UGC ad for [PRODUCT]. Include: the one message that
must land, 3 hook options to film, a 30-second script outline (hook → problem →
demo → result → CTA), shot list, and the 5 things NOT to do (sounding scripted,
over-polishing, burying the hook...).
```

## 36. The $500 Test Budget Plan
```
I have $500 to test paid ads for [BUSINESS]. Design the leanest valid test:
platform choice for [AUDIENCE], 1 campaign structure, 3 ad angles to split
test, daily budget, kill criteria (when to turn an ad off), and success
criteria (what number justifies scaling). Assume I've never run ads.
```

# PART 5 — SEO & CONTENT (37–43)

## 37. The Keyword Opportunity Map
```
You are an SEO strategist. Business: [BUSINESS + LOCATION IF LOCAL].
Map 20 keyword opportunities in a table: keyword, search intent (info/
commercial/transactional), difficulty guess (low/med/high), and content type
to create. Prioritize low-competition, high-buyer-intent terms a new site can
actually rank for. Mark the top 5 to attack first.
```

## 38. The Blog Post Writer
```
You are an expert content writer. Write a blog post targeting the keyword
"[KEYWORD]" for [BUSINESS]. Requirements: title with the keyword, compelling
intro (no "in today's world" fluff), H2/H3 structure, short paragraphs,
a comparison table or list where useful, FAQ section with 4 questions, and a
CTA to [OFFER]. 1,200–1,500 words. Write like a knowledgeable friend, not an
encyclopedia. After, give me the meta description (≤155 chars).
```

## 39. The Local SEO Dominator
```
You are a local SEO expert. Business: [BUSINESS] in [CITY]. Give me the
complete local playbook: Google Business Profile optimization checklist
(categories, services, posts cadence), 10 review-generation tactics, 5 local
content ideas, citation sources for my industry, and the 3 things that move
local rankings most.
```

## 40. The Content Repurposer
```
Here is my content: [PASTE BLOG POST/VIDEO TRANSCRIPT]. Repurpose into:
3 social posts (different angles), 1 email, 1 short-video script, 5 quote
graphics (text only), and 1 thread/carousel outline. Keep my voice; each
piece must stand alone.
```

## 41. The FAQ Page Goldmine
```
Generate the 15 questions people ask before buying from [BUSINESS TYPE].
Write concise, honest answers (50–80 words each) optimized to appear in
Google's People-Also-Ask. Flag the 3 answers that most influence the buying
decision so I feature them prominently.
```

## 42. The Comparison Content Play
```
You are an SEO copywriter. Write a "[MY PRODUCT] vs [COMPETITOR/ALTERNATIVE]"
comparison page that is genuinely fair (fairness builds trust and converts
better). Include: honest comparison table, who should pick them, who should
pick us, and FAQ. My advantages: [LIST]. Their advantages: [LIST or "be
reasonable"].
```

## 43. The Authority Guest Pitch
```
Write 3 guest post / podcast pitch emails for [MY NICHE] targeting [TYPE OF
SITE/SHOW]. Each under 120 words: one-line credibility, 3 specific topic ideas
with working titles tailored to THEIR audience, and an easy yes. No "I hope
this email finds you well."
```

# PART 6 — CONVERSION & SALES (44–50)

## 44. The Sales Page Skeleton
```
You are a long-form sales copywriter. Build the full sales page for
[OFFER + PRICE] to [AUDIENCE]. Sections in order: pattern-interrupt headline,
lead (their current pain, vividly), the shift/mechanism, offer stack with
value anchoring, proof section, guarantee, FAQ (7 objections), price
justification, final close. Write complete copy, not placeholders — I'll edit.
```

## 45. The DM Sales Script
```
You are a social selling coach. Someone DMs asking about [OFFER]. Write the
conversation flow: warm opener, 3 discovery questions (find their pain before
pitching), transition to offer, price delivery + silence guidance, and
responses to "too expensive", "need to think", and "how is this different?"
Natural, human, zero pressure-tactics.
```

## 46. The Discovery Call Frame
```
Create a 30-minute sales call structure for [SERVICE + PRICE]: 5-min rapport +
frame setting, 15-min discovery (give me the 7 exact questions), 5-min
tailored pitch template, 5-min close + objections. Include the exact words for
asking for the sale without being weird about it.
```

## 47. The Proposal Template
```
Write a client proposal template for [SERVICE]. One page: their situation
(mirrors their words), the goal, my recommended plan (3 phases), timeline,
investment (3 options: minimal/recommended/premium), guarantee, and next step
with deadline. Persuasive but professional — the option design should make
"recommended" the obvious choice.
```

## 48. The Price Increase Announcement
```
Write the price-increase communication for [BUSINESS]: raising [OFFER] from
[OLD] to [NEW] on [DATE]. Three pieces: email to existing customers
(grandfathering decision: [YES/NO]), social announcement, and how to
handle "why?" replies. Confident, no over-explaining, frames the increase
around delivered value.
```

## 49. The Referral Engine
```
Design a simple referral program for [BUSINESS]. Include: the incentive
structure (both sides win), the exact ask message customers receive after a
great experience, when to trigger it, a tracking method that needs no special
software, and 3 ways to remind without nagging.
```

## 50. The Monthly Marketing Review
```
You are my marketing advisor. Here are this month's numbers: [PASTE: traffic,
leads, sales, top content, ad spend/results]. Analyze: what worked and why,
what to kill, what to double, and the top 3 priorities for next month.
Be direct — tell me what I'm avoiding that I shouldn't be.
```
